# New Hoplite organization

A Chrome / Edge extension that opens Hoplite’s own new-organization onboarding with Free requested. It needs no extension permissions, stores nothing, and never handles credentials or payment information.

1. Open `chrome://extensions` (or `edge://extensions`) and enable **Developer mode**.
2. Choose **Load unpacked** and select the `extension` directory containing `manifest.json`.
3. Click **New Hoplite organization** in the extensions menu, then **Create with Free**.
4. Sign in if prompted and finish setup on Hoplite. Check that the plan shown is **Free** before confirming. Hoplite handles eligibility, verification and organization creation; opening the extension alone does not create anything.
